# Medical_data_visualisation_system

[![Смотреть дашборд](https://img.shields.io/badge/🚀_DataLens-Туберкулёз_в_РФ_и_Иркутской_области-2a6d8f?style=for-the-badge&logo=databricks&logoColor=white)](https://datalens.yandex/s3vte8xmi1wkc)

**Цель проекта** – создание системы поддержки принятия обоснованных управленческих решений для повышения эффективности противотуберкулёзной помощи населению Иркутской области.

---

## 📌 Основные задачи

- Консолидация и унификация данных из 6+ источников (формы №8, №33, №30, статистика Иркутскстата, ЦНИИОИЗ, внутренние отчёты).
- Расчёт производных метрик (на 100 тыс. населения, динамика, структура, доля женщин/детей).
- Разработка интерактивных визуализаций в Yandex DataLens.
- Итоговый отчёт и передача результатов заказчику.

## 👥 Целевая аудитория

- Главный врач ИОПТД
- Заведующий организационно-методическим отделом

## 📁 Репозиторий содержит

| Ноутбук | Описание |
|---------|----------|
| `1_Таблицы_ИГМУ_парсинг_обработка.ipynb` | Извлечение данных из Excel/PDF, очистка, сведение |
| `2_Численность_населения_ИО.ipynb` | Половозрастная структура (Иркутскстат) |
| `3_Расчет_индикаторов_EDA.ipynb` | Расчёт основных эпидпоказателей, EDA,тренды |
| `4_Классификатор.ipynb` | Приведение номенклатуры и кодификаторов |
| `5_Статданные_РФ.ipynb` | Сбор данных по РФ и федеральным округам |
| `6_Отчет_по_проекту_ИГМУ.ipynb` | Формирование итогового отчёта |

## 🧩 Ключевые источники данных

- Форма №8 (заболеваемость по полу/возрасту)  
- Форма №33 (контингенты, МЛУ, госпитализация, летальность)  
- Форма №30 (профилактические осмотры)  
- Сборник ЦНИИОИЗ «Социально значимые заболевания»  
- Данные Иркутскстата (численность, возрастной состав)  

## 📊 Результат

Готовый дашборд в DataLens – доступен по кнопке в начале файла.  
Все расчётные датасеты экспортированы в CSV и могут быть переиспользованы.
